# Store Management Dashboard

Accessories-only store dashboard for inventory, supplies, inter-store transfers, store requests, and approvals.

## Scripts

```bash
npm install
npm run dev
```

Sign in with any email and password — the app falls back to a demo session when the API is unavailable.

## Stack

React 19, Vite 7, Tailwind CSS 3, React Router 7. Styling tokens live in `src/theme/`.
